##### Explanation
The possible outcomes are: Monday-10min, Monday-15min, Wednesday-10min, Wednesday-15min. With 2 day options and 2 duration options, there are $2 \times 2 = 4$ total possible outcomes. Each combination of day and duration represents one distinct outcome. This demonstrates the fundamental counting principle, which states that if one event can occur in $m$ ways and a second independent event can occur in $n$ ways, then the two events together can occur in $m \times n$ ways.

##### Distractors

###### Option 1
This represents counting only one characteristic of the assignment. A test-taker may select this if they count only the options for one variable (either the 2 days or the 2 durations) without considering that both characteristics must be combined to determine all possible outcomes.

###### Option 3
This represents a misapplication of combination formulas. A test-taker might identify four individual components (Monday, Wednesday, 10 minutes, and 15 minutes) and incorrectly calculate the number of ways to choose a pair from that set of four ($\binom{4}{2} = 6$). This error occurs when a student treats all individual options as a single pool of items rather than recognizing that they must select one option from each of the two independent categories.

###### Option 4
This represents doubling the correct answer or counting each combination twice. A test-taker may select this if they mistakenly count each outcome twice (perhaps once for each characteristic), multiply by an extra factor ($4 \times 2 = 8$), or incorrectly assume there are 4 options for one of the characteristics instead of 2.
