#### Task Description

A hospital pharmacy tracks adverse drug reactions (ADRs) to a commonly prescribed antibiotic. The manufacturer's clinical trial of 45,000 patients established an ADR rate of 8%. After the pharmacy's first 30 patients received this antibiotic, 5 experienced adverse reactions—an observed rate of approximately 17%.

![Bar chart comparing two ADR rates side by side: the pharmacy's observed rate of approximately 17% based on 30 patients and the manufacturer's reported rate of 8% based on 45,000 clinical trial patients, with each bar labeled by its sample size.](https://k3-production-bucket.s3.us-east-1.amazonaws.com/uploads/krqEzM6ojBFTEvitG_ywkXwBynsg3CJpkXm_plot_7.png)

How should the pharmacy interpret the difference between its observed 17% ADR rate and the manufacturer's established 8% rate?

###### Option 2 Incorrect

###### Option 3 Correct
As a result likely driven by the small patient sample, where the observed rate should stabilize closer to 8% as more patients are tracked.


###### Option 4 Incorrect
As an indication that the ADR rate will continue to increase by approximately 9% for every additional 30 patients tracked.

##### Explanation
The law of large numbers states that as the number of observations increases, the observed proportion converges toward the true probability. The pharmacy's sample of only 30 patients is highly susceptible to random variation, which can produce an observed ADR rate (17%) that deviates substantially from the established rate (8%). As the pharmacy tracks more patients over time, the observed rate is expected to move closer to the manufacturer's 8% figure. The current discrepancy does not constitute reliable evidence that the drug is more dangerous than reported; it reflects the natural instability of proportions calculated from small samples.

##### Distractors

###### Option 1
This targets students who prioritize the recency of data over the size of the sample. It incorrectly suggests that a small, local sample (n=30) can invalidate the results of a massive, rigorous clinical trial (n=45,000) simply because the data was collected more recently.

###### Option 2
This targets the concept of independence. While it is true that each patient's reaction is an independent event, independence does not mean a 30-patient sample is equally reliable as a 45,000-patient trial. The law of large numbers explains that larger samples produce more stable and accurate estimates of the true proportion. A student selecting this option confuses the idea of independent trials with the precision of an estimate.

###### Option 4
This targets the misconception of linear trends in probability. It suggests that a deviation from the expected rate indicates a continuing upward trend, whereas the law of large numbers dictates that larger samples will lead to a stabilization of the rate toward the true probability (8%) rather than a predictable, compounding increase.

import matplotlib.pyplot as plt
import numpy as np

def setup_style():
    """Configure matplotlib style to match scientific plotting standards."""
    plt.rcParams['font.family'] = 'DejaVu Sans'
    plt.rcParams['font.size'] = 20
    plt.rcParams['axes.titlesize'] = 20
    plt.rcParams['axes.titleweight'] = 'bold'

    plt.rcParams['axes.labelsize'] = 20
    plt.rcParams['axes.labelcolor'] = '#333333'
    plt.rcParams['xtick.labelsize'] = 20
    plt.rcParams['ytick.labelsize'] = 20
    plt.rcParams['xtick.color'] = '#666666'
    plt.rcParams['ytick.color'] = '#666666'
    plt.rcParams['axes.edgecolor'] = '#333333'
    plt.rcParams['axes.linewidth'] = 1.0
    plt.rcParams['grid.color'] = '#CCCCCC'
    plt.rcParams['grid.linewidth'] = 0.5
    plt.rcParams['figure.facecolor'] = 'white'
    plt.rcParams['axes.facecolor'] = 'white'

def plot_image():
    """Generate the scientific visualization."""
    setup_style()

    fig, ax = plt.subplots(figsize=(10.24, 10.24))

    # Hide top and right spines
    ax.spines['top'].set_visible(False)
    ax.spines['right'].set_visible(False)

    # Data configuration
    categories = ["Pharmacy Data", "Manufacturer Trial"]
    values = [16.7, 8.0]  # Values as specified in description (16.7% and 8%)
    colors = ['#1f77b4', '#ff7f0e'] # Scientific blue and orange
    sample_sizes = ["n = 30", "n = 45,000"]

    # Create vertical bar chart
    bars = ax.bar(categories, values, color=colors, width=0.6, zorder=3)

    # Set axes labels and title
    ax.set_ylabel("ADR Rate (%)")
    ax.set_title("Adverse Drug Reaction (ADR) Rates Comparison", pad=20)

    # Configure Y-axis scale and ticks
    ax.set_ylim(0, 20)
    ax.set_yticks(np.arange(0, 21, 5))

    # Configure grid (horizontal only, behind data)
    ax.grid(axis='y', zorder=0)
    
    # Tick styling (outward facing)
    ax.tick_params(axis='both', direction='out', length=6, width=1)

    # Add specific annotations above bars
    for bar, text in zip(bars, sample_sizes):
        height = bar.get_height()
        ax.text(bar.get_x() + bar.get_width() / 2, height + 0.5, 
                text, 
                ha='center', va='bottom', 
                color='#333333', fontsize=20)

    plt.tight_layout()
    return fig

if __name__ == "__main__":
    fig = plot_image()
    plt.savefig('plot.png', dpi=150, bbox_inches='tight')
    print("Image saved as plot.png")
