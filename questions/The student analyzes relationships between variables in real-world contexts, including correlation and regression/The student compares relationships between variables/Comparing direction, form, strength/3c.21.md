#### Task Description

**Given:** A college learning center examined how two student behaviors relate to performance in an introductory course. The figure shows two scatterplots from the same group of students: **Plot A** compares *optional practice sets completed* to *final exam score*, and **Plot B** compares *hours of sleep the night before the final* to *final exam score*.

![two scatterplots labeled A and B showing student behaviors versus final exam score](https://k3-production-bucket.s3.amazonaws.com/uploads/c5440578-b89a-4626-9b53-74dd049e1a66_optimized.jpg)

Based on this figure, what conclusion best compares the **direction, form, and strength** of the relationships in Plot A and Plot B?

#### Quiz Options

###### Option 1 Incorrect
Optional practice sets completed and hours of sleep both show strong positive linear associations with final exam score.


###### Option 2 Incorrect
Optional practice sets completed show little to no linear association with final exam score, while hours of sleep show a strong positive linear association with final exam score.


###### Option 3 Correct
Optional practice sets completed show a stronger positive linear association with final exam score than hours of sleep do, and the sleep relationship appears mostly non-linear.


###### Option 4 Incorrect
Optional practice sets completed show a negative linear association with final exam score, while hours of sleep show a positive linear association with final exam score.

##### Explanation
Plot A shows points that follow an upward, roughly straight-line pattern with relatively tight clustering, indicating a stronger **positive linear** association with final exam score. Plot B shows a relationship that is not well-described by a straight line (a mostly **non-linear** pattern), so its **linear** association is weaker. Therefore, Plot A has the stronger positive linear relationship.

##### Distractors

###### Option 1
This choice treats both plots as strong **positive linear** relationships. A common error is to interpret any upward tendency (or any relationship at all) as “strong linear,” even when one plot is clearly not linear.

###### Option 2
This reverses the comparison by attributing the stronger positive linear association to sleep rather than practice sets, which would be chosen by students who misread the plots’ overall patterns or confuse “any pattern” with “linear strength.”

###### Option 4
This choice misinterprets the **direction** in Plot A by claiming it is negative. It targets students who confuse upward vs. downward trends when reading scatterplots.

```python
import matplotlib.pyplot as plt
import numpy as np

def setup_style():
    """Configure matplotlib style to match scientific plotting standards."""
    plt.rcParams['font.family'] = 'DejaVu Sans'
    plt.rcParams['font.size'] = 10
    plt.rcParams['axes.titlesize'] = 14
    plt.rcParams['axes.titleweight'] = 'bold'
    plt.rcParams['axes.labelsize'] = 12
    plt.rcParams['axes.labelcolor'] = '#333333'
    plt.rcParams['xtick.labelsize'] = 10
    plt.rcParams['ytick.labelsize'] = 10
    plt.rcParams['xtick.color'] = '#666666'
    plt.rcParams['ytick.color'] = '#666666'
    plt.rcParams['axes.edgecolor'] = '#333333'
    plt.rcParams['axes.linewidth'] = 1.0
    plt.rcParams['grid.color'] = '#CCCCCC'
    plt.rcParams['grid.linewidth'] = 0.5
    plt.rcParams['figure.facecolor'] = 'white'
    plt.rcParams['axes.facecolor'] = 'white'

def plot_image():
    """Generate the scientific visualization."""
    setup_style()

    # Create figure with specified dimensions (10.24x10.24 inches)
    # Using subplot adjustment to ensure side-by-side plots have good aspect ratio within square canvas
    fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(10.24, 10.24))
    
    # Adjust margins to center the plots vertically and prevent them from being too tall
    plt.subplots_adjust(left=0.1, right=0.95, top=0.7, bottom=0.3, wspace=0.3)

    # ---------------------------------------------------------
    # DATA GENERATION
    # ---------------------------------------------------------
    np.random.seed(42) # Ensure reproducibility
    n_points = 50

    # PLOT A DATA: Strong positive linear
    # x range 0-15, y range 40-100
    x_a = np.random.uniform(0, 15, n_points)
    # Trend: starts ~50, ends ~95. Slope approx 3.
    noise_a = np.random.normal(0, 2.0, n_points) # Low noise for strong correlation
    y_a = 3.0 * x_a + 50 + noise_a
    y_a = np.clip(y_a, 40, 100) # Keep within axis limits

    # PLOT B DATA: Weak positive
    # x range 2-10, y range 40-100
    x_b = np.random.uniform(2, 10, n_points)
    # Trend: slight upward drift. Loose cloud.
    # Vertical spread significantly larger.
    noise_b = np.random.normal(0, 9.0, n_points) # High noise for weak correlation
    y_b = 1.5 * x_b + 60 + noise_b
    y_b = np.clip(y_b, 40, 100)

    # ---------------------------------------------------------
    # PLOTTING
    # ---------------------------------------------------------
    
    # Plot A Configuration
    ax1.scatter(x_a, y_a, color='#1f77b4', edgecolor='black', linewidth=0.8, s=60, zorder=3)
    ax1.set_title("Plot A", pad=15)
    ax1.set_xlabel("Optional Practice Sets Completed")
    ax1.set_ylabel("Final Exam Score")
    ax1.set_xlim(0, 15)
    ax1.set_ylim(40, 100)
    
    # Plot B Configuration
    ax2.scatter(x_b, y_b, color='#1f77b4', edgecolor='black', linewidth=0.8, s=60, zorder=3)
    ax2.set_title("Plot B", pad=15)
    ax2.set_xlabel("Hours of Sleep")
    ax2.set_ylabel("Final Exam Score")
    ax2.set_xlim(2, 10)
    ax2.set_ylim(40, 100)

    # Common Styling for both axes
    for ax in [ax1, ax2]:
        # Hide top and right spines
        ax.spines['top'].set_visible(False)
        ax.spines['right'].set_visible(False)
        
        # Grid behind data
        ax.grid(True, linestyle='-', alpha=1.0)
        ax.set_axisbelow(True)
        
        # Outward ticks
        ax.tick_params(direction='out', length=4, width=1)

    return fig

if __name__ == "__main__":
    fig = plot_image()
    plt.savefig('plot.png', dpi=150, bbox_inches='tight')
    print("Image saved as plot.png")
```
