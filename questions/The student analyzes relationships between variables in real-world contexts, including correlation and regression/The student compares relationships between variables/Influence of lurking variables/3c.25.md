#### Task Description

**Given:** A study at a weight management clinic finds a strong positive correlation between the number of nutrition counseling sessions patients attend per month and the total amount of weight they lose. A clinic director concludes that scheduling all patients for additional counseling sessions will increase their weight loss. A data analyst proposes that patients' level of self-discipline may be a lurking variable in this relationship.

How would level of self-discipline function as a lurking variable in this observed relationship?

#### Quiz Options

###### Option 1 Correct
Higher self-discipline makes patients more likely to attend scheduled sessions, and it also drives dietary adherence that causes weight loss independently.


###### Option 2 Incorrect
Higher self-discipline motivates patients to attend more sessions, and the guidance received in those sessions then directly causes their greater weight loss.


###### Option 3 Incorrect
Higher self-discipline lowers the risk of stress-eating, an outcome unrelated to how many counseling sessions a patient is scheduled to attend.


###### Option 4 Incorrect
Higher self-discipline allows patients to start the program immediately, and this longer duration leads to both more monthly sessions and greater total weight loss.

##### Explanation
A lurking variable must independently influence both the observed independent and dependent variables, creating a correlation that does not reflect direct causation. For self-discipline to function as a lurking variable, it must simultaneously drive counseling session attendance (disciplined patients are more reliable) AND weight loss (disciplined patients adhere to diets independently) through two separate pathways. This would make the observed correlation between session frequency and weight loss partly or entirely spurious—scheduling more sessions for all patients would not necessarily produce more weight loss because the underlying self-discipline was driving both variables independently.

##### Distractors
###### Option 2
Higher self-discipline motivating more attendance, which then causes weight loss — This describes a causal chain (self-discipline → more sessions → weight loss) that actually supports the clinic director's original conclusion that more sessions cause weight loss. It does not describe a lurking variable because it does not show discipline independently influencing both variables through separate pathways.

###### Option 3
Higher self-discipline reducing stress-eating — This connects self-discipline to only one of the two observed variables (weight loss) and explicitly states it is unrelated to the other variable (counseling session frequency). A lurking variable must influence both observed variables, so this does not describe a lurking variable mechanism.

###### Option 4
Higher self-discipline allowing earlier start times — This introduces program duration as a mediating variable through which discipline influences both session frequency and weight loss via a single causal chain. A lurking variable creates a spurious correlation by independently driving both variables, not by feeding through a single intermediary that then branches to both outcomes.
