**Given:** A software company has 50 testers use two database systems and records the time it takes each system to return results for each tester.

##### Domain

##### Explanation
Time to return results is the dependent (response) variable in this study because it is the outcome the company measures to determine whether the choice of database system makes a difference. The same 50 testers each use both database systems on their own workstations, which makes this a paired design—each tester serves as their own control, and the two measurements per tester form matched pairs. The database system is the explanatory (independent) variable—it is the condition the company deliberately varies. Recognizing both the variable's role (dependent) and the study's paired structure is essential to selecting the correct analysis approach.

##### Distractors
###### Option 1
This option reverses the roles of the explanatory and response variables. The time to return results is not the factor being manipulated; the choice of database system is. Students who select this may confuse which variable is being deliberately changed with which variable is being observed for change.

###### Option 3
This option correctly identifies time as the outcome but mischaracterizes the study design as independent. The scenario states that the same 50 testers each use both database systems, meaning measurements are paired by tester. Students who select this may not recognize that measuring the same subjects under two conditions creates paired data rather than two independent groups.

###### Option 4
This option mistakes the response variable for a summary statistic. Students who select this may conflate the act of recording individual measurements with the process of computing an average, or may not recognize that time to return results is a variable observed across testers rather than a single calculated value.
