#### Internal Notes

##### Competency

##### Aligned Content
Explanatory vs response variables

##### Explanation
The explanatory variable is hours spent on training because it is the factor being examined as the potential cause or predictor. The company wants to see if training hours influence (predict) the number of bugs found, making bug count the response variable.

##### Domain

##### Distractors
###### Option 1
Number of bugs found — Confuses explanatory with response variable
Students who select this reverse the relationship, thinking the response they want to explain is the explanatory variable. This reflects confusion about which variable is thought to influence the other.

###### Option 3
Years of developer experience — Introduces a plausible extraneous variable
This distractor represents a measurable variable that could influence the outcome but is not the specific factor being tested in this study design. Students might select this if they focus on external factors rather than the specific relationship described.

###### Option 4
Lines of code reviewed — Introduces a plausible confounding variable
This is a quantitative variable related to the code review process. Students may confuse this with the explanatory variable because it is a measurable factor that logically impacts the number of bugs found, though it is not the focus of this specific study.
