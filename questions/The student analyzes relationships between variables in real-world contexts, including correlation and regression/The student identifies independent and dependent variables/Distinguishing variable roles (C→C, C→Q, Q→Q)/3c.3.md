#### Task Description

**Given:** A retail company records the average quarterly revenue (in dollars) for each of its stores and groups each store by format: online-only, brick-and-mortar, or hybrid. An analyst wants to determine whether store format helps explain differences in quarterly revenue.

How should the variables in this analysis be classified by type and assigned by role?

##### Explanation
This analysis involves two tasks: classifying each variable by type and assigning each variable a role. **Store format** takes on category labels (online-only, brick-and-mortar, hybrid) rather than numerical measurements, so it is a **categorical** variable. Because the analyst is investigating whether store format helps explain revenue differences, store format serves as the **explanatory** variable. **Quarterly revenue** is measured in dollars, making it a **quantitative** variable. Because revenue is the outcome the analyst is trying to understand, it is the **response** variable. The correct pairing is therefore a categorical explanatory variable (store format) predicting a quantitative response variable (quarterly revenue), representing a C→Q relationship.

##### Distractors
###### Option 2

It targets students who recognize the difference between categorical and quantitative variables but misinterpret the direction of the relationship, incorrectly treating the outcome (revenue) as the predictor and the predictor (store format) as the outcome.

###### Option 3
This distractor assigns the correct roles but misclassifies store format as quantitative. It targets students who understand directional relationships but confuse categorical groupings (named categories such as store formats) with quantitative measurements, perhaps because they associate any variable in a statistical analysis with numerical data.

###### Option 4
This distractor both reverses the variable roles and misclassifies quarterly revenue as categorical. It targets students who struggle with both concepts simultaneously—confusing which variable is the predictor versus the outcome and incorrectly treating a continuous dollar measurement as a categorical variable, possibly by thinking of revenue in grouped tiers rather than as a measured quantity.
