#### Task Description

A college’s academic support office studied whether attending academic coaching visits is related to students’ first-semester grade point average (GPA). A linear regression trend line was fit:

$$
\widehat{\text{GPA}} = 2.5 + 0.10(\text{Visits})
$$

where **Visits** is the number of coaching visits during the semester and GPA is on a 0.0–4.0 scale.

![Graphic showing a regression-summary panel with the fitted line equation relating coaching visits to GPA](https://k3-production-bucket.s3.amazonaws.com/uploads/5f9af6fe-fc0d-45d0-9eeb-38bbf4ab7d99_optimized.jpg)

How should the **intercept (2.5)** and **slope (0.10)** of this trend line be interpreted in context?

#### Quiz Options

###### Option 1 Incorrect
It predicts that a student with 0 visits would have a GPA of about 0.10, and each additional visit is associated with about 2.5 higher GPA.


###### Option 2 Incorrect
It predicts that a student with 0 visits would have a GPA of about 2.5, and each additional visit is associated with about 0.10 lower GPA.


###### Option 3 Correct
It predicts that a student with 0 visits would have a GPA of about 2.5, and each additional visit is associated with about 0.10 higher GPA.


###### Option 4 Incorrect
It predicts that a student with a GPA of 0 would have about 2.5 visits, and each additional GPA point is associated with about 0.10 more visits.

##### Explanation
In a regression line of the form \(\hat{y}=b_0+b_1x\), the intercept \(b_0\) is the predicted value of \(y\) when \(x=0\), and the slope \(b_1\) is the predicted change in \(y\) for a 1-unit increase in \(x\). Here, the intercept 2.5 means the model predicts a GPA of about 2.5 for a student with 0 coaching visits, and the slope 0.10 means each additional visit is associated with an increase of about 0.10 GPA points in the predicted GPA.

##### Distractors

###### Option 1
Swaps the roles of the slope and intercept, a common mistake (treating 0.10 as the starting GPA and 2.5 as the per-visit change).

###### Option 2
Uses the correct intercept but incorrectly interprets the slope as negative, reversing the direction of association.

###### Option 4
Reverses the variables, treating the model as if it predicts Visits from GPA (interpreting the coefficients in the wrong direction).

```python
import matplotlib.pyplot as plt
import numpy as np

def setup_style():
    """Configure matplotlib style to match scientific plotting standards."""
    plt.rcParams['font.family'] = 'DejaVu Sans'
    plt.rcParams['font.size'] = 10
    plt.rcParams['axes.titlesize'] = 14
    plt.rcParams['axes.titleweight'] = 'bold'
    plt.rcParams['axes.labelsize'] = 12
    plt.rcParams['axes.labelcolor'] = '#333333'
    plt.rcParams['xtick.labelsize'] = 10
    plt.rcParams['ytick.labelsize'] = 10
    plt.rcParams['xtick.color'] = '#666666'
    plt.rcParams['ytick.color'] = '#666666'
    plt.rcParams['axes.edgecolor'] = '#333333'
    plt.rcParams['axes.linewidth'] = 1.0
    plt.rcParams['grid.color'] = '#E0E0E0'
    plt.rcParams['grid.linewidth'] = 0.5
    plt.rcParams['figure.facecolor'] = 'white'
    plt.rcParams['axes.facecolor'] = 'white'
    plt.rcParams['xtick.direction'] = 'out'
    plt.rcParams['ytick.direction'] = 'out'

def plot_image():
    """Generate the scientific visualization."""
    setup_style()

    fig, ax = plt.subplots(figsize=(10.24, 10.24))

    # Hide top and right spines
    ax.spines['top'].set_visible(False)
    ax.spines['right'].set_visible(False)

    # Set axis ranges
    ax.set_xlim(0, 15)
    ax.set_ylim(0.0, 4.0)

    # Configure ticks
    # X-axis: 0 to 15, tick marks every 3 units based on description preference
    ax.set_xticks(np.arange(0, 16, 3))
    # Y-axis: 0.0 to 4.0, tick marks every 0.5 units
    ax.set_yticks(np.arange(0.0, 4.5, 0.5))

    # Add grid (behind data)
    ax.set_axisbelow(True)
    ax.grid(True)

    # Generate Data
    # 35 points spread across the range
    np.random.seed(42) # Ensure reproducibility
    x = np.random.uniform(0.5, 14.5, 35)
    
    # Regression equation: y = 2.5 + 0.10x
    slope = 0.10
    intercept = 2.5
    
    # Add noise (moderate variance)
    noise = np.random.normal(0, 0.15, 35)
    y = intercept + slope * x + noise
    
    # Clamp GPA values to logical limits (0.0 - 4.0) for realism
    y = np.clip(y, 0.0, 4.0)

    # Plot Scatter Points
    # Blue (#1f77b4) with small dark border
    ax.scatter(x, y, 
               color='#1f77b4', 
               edgecolors='#0b4a75', 
               linewidth=0.8, 
               s=100, 
               zorder=3,
               alpha=0.9)

    # Plot Trend Line
    # Equation: y = 2.5 + 0.10x
    # Line from x=0 to x=15
    line_x = np.array([0, 15])
    line_y = intercept + slope * line_x
    
    ax.plot(line_x, line_y, 
            color='#d62728', 
            linewidth=2.5, 
            zorder=4,
            label='Fit: $\widehat{GPA} = 2.5 + 0.10(Visits)$')

    # Labels and Title
    ax.set_title("Coaching Visits vs. First-Semester GPA", pad=20)
    ax.set_xlabel("Number of Coaching Visits", labelpad=10)
    ax.set_ylabel("First-Semester GPA", labelpad=10)

    plt.tight_layout()
    return fig

if __name__ == "__main__":
    fig = plot_image()
    plt.savefig('plot.png', dpi=150, bbox_inches='tight')
    print("Image saved as plot.png")
```
