#### Task Description

A university admissions office uses a linear model to predict first-year grade point average (GPA) based on the number of Advanced Placement (AP) courses a student completed in high school. The table below shows predicted GPAs from this model for selected numbers of AP courses.

| AP Courses Completed | Predicted First-Year GPA |
|---|---|
| 1 | 2.2 |
| 3 | 2.6 |
| 5 | 3.0 |

According to this model, what is the predicted first-year GPA for a student who completed 9 AP courses?

##### Explanation
From the table, each increase of 2 AP courses corresponds to an increase of 0.4 in predicted GPA. The per-course rate of change (slope) is 0.4 ÷ 2 = 0.2 GPA points per AP course. To predict the GPA for a student with 9 AP courses, start from the last known value (5 courses, GPA of 3.0) and account for the 4 additional courses: 3.0 + 0.2(4) = 3.0 + 0.8 = 3.8. Alternatively, the intercept is 2.2 − 0.2(1) = 2.0, so the full equation is Predicted GPA = 2.0 + 0.2 × (AP courses), giving 2.0 + 0.2(9) = 3.8.

##### Distractors
###### Option 1
The student correctly identified the per-course rate of change as 0.2 but applied it only once from the last table entry, calculating 3.0 + 0.2 = 3.2, rather than multiplying by the 4-course increase from 5 to 9.

###### Option 2
The student continued the table's row-to-row pattern by adding 0.4 to the last entry, calculating 3.0 + 0.4 = 3.4. This treats the jump from 5 to 9 AP courses as though it were the same 2-course increment shown between consecutive rows in the table, without adjusting for the actual 4-course gap.

###### Option 4
The student used the row-to-row increment of 0.4 as if it were the per-course rate, calculating 3.0 + 0.4(4) = 4.6. This confuses the change across a 2-course interval with the change per single course, effectively doubling the true rate of change.
