##### Domain
Business

##### Explanation

#### Internal Notes

##### Competency
The student interprets real-world data using graphical displays and descriptive statistics.

##### Evidence Statement
The student identifies types of data.

##### Aligned Content
Classifying data types

##### Domain
Business

##### Explanation
The number of customers is quantitative discrete data. It is quantitative because it represents a numerical measurement that can be used in mathematical operations. It is discrete because customers can only be counted in whole numbers—you cannot have 2.5 customers. Discrete data have gaps between possible values, while continuous data can take any value within a range.

##### Distractors

###### Option 1
Quantitative continuous — Confuses discrete and continuous data

This is the most common error. Students may recognize that the data is quantitative but fail to distinguish between discrete (countable, whole numbers) and continuous (measurable, any value in a range) data. Continuous data examples include height, weight, or temperature.

###### Option 2
Categorical nominal — Confuses quantitative and categorical data

This targets students who may not recognize that numerical counts are quantitative data. Nominal data are categories without inherent order, such as store location type or product brand.

###### Option 3
Categorical ordinal — Confuses quantitative data with ranked categories

This targets students who confuse counted numerical data with ordered categorical data. Ordinal data represent ranked categories, such as satisfaction ratings (low, medium, high) or education levels.

##### Competency

##### Evidence Statement
The student identifies patterns and outliers in graphical displays

##### Aligned Content
Peaks/modes

##### Explanation
The tallest bar in a histogram represents the interval with the highest frequency—this is the modal class of the distribution. The modal class indicates the most commonly occurring range of values. The median is the middle value when data is ordered and requires knowing the total count to locate. It is not necessarily in the tallest bar, especially in skewed distributions.

Mean/Median

import numpy as np

def setup_style():
    """Configure matplotlib style to match scientific plotting standards."""
    plt.rcParams['font.family'] = 'DejaVu Sans'
    plt.rcParams['font.size'] = 10
    plt.rcParams['axes.titlesize'] = 14

    plt.rcParams['grid.linewidth'] = 0.5
    plt.rcParams['figure.facecolor'] = 'white'
    plt.rcParams['axes.facecolor'] = 'white'

def plot_image():

    setup_style()

    fig, ax = plt.subplots(figsize=(10.24, 10.24))

    # Hide top and right spines
    ax.spines['top'].set_visible(False)
    ax.spines['right'].set_visible(False)

    # Data
    hospitals = ['Hospital A', 'Hospital B']
    values = [4.8, 4.2]

    # Create bar chart
    # Using a specific width to ensure bars look proportionate on the square canvas
    ax.bar(hospitals, values, color='#1f77b4', width=0.5, zorder=3)

    # Set Axes Labels and Title
    ax.set_title("Average Length of Hospital Stay", pad=20)
    ax.set_xlabel("Hospital")

    # Set Y-axis scale and ticks
    # The scale must start at 4.0 and end at 5.0
    ax.set_ylim(4.0, 5.0)
    
    # Set tick marks every 0.2 units
    ticks = np.arange(4.0, 5.1, 0.2)
    ax.set_yticks(ticks)

    # Configure grid (Horizontal only, behind data)
    ax.grid(axis='y', linestyle='-', alpha=1.0)
    ax.set_axisbelow(True)

    # Ensure tick marks point outward
    ax.tick_params(axis='both', which='major', direction='out', length=6, width=1)

    plt.tight_layout()
    return fig
