#### Task Description

**Given:** A retail store calculates daily profit using the expression:
$$
\text{Profit} = \text{Revenue} - (\text{Fixed Costs} + \text{Variable Cost} \times \text{Units Sold})
$$

What is today's profit given a Revenue of $4,800, Fixed Costs of $1,000, a Variable Cost per unit of $6, and 200 Units Sold?

##### Explanation
Following order of operations: First calculate inside the parentheses, starting with multiplication: $6 \times 200 = 1,200$. Then add: $1,000 + 1,200 = 2,200$. Finally subtract from revenue: $4,800 - 2,200 = 2,600$. Therefore, today's profit is \$2,600.

##### Distractors

###### Option 2
\$3,594 - Results from performing addition before multiplication inside the parentheses, treating $6 \times 200$ as $6 + 200$: $4800 - (1000 + 6 + 200) = 4800 - 1206 = 3594$

###### Option 3
\$3,800 - Results from only subtracting the fixed costs and completely forgetting to account for the variable costs in the calculation: $4800 - 1000 = 3800$

###### Option 4
\$5,000 - Results from ignoring the parentheses grouping entirely and evaluating with standard operator precedence (multiplication before addition/subtraction): $4800 - 1000 + 6 \times 200 = 4800 - 1000 + 1200 = 5000$
