#### Task Description

**Given:** A research study found that 4 interviewers can complete 28 interviews in one day. The study coordinator needs to complete 63 interviews in one day.

Which proportion correctly sets up the relationship to find the number of interviewers needed?

#### Quiz Options

###### Option 1 Incorrect
$\frac{4}{28} = \frac{63}{x}$


###### Option 2 Incorrect
$\frac{28}{4} = \frac{x}{63}$


###### Option 3 Incorrect
$\frac{4}{x} = \frac{63}{28}$


###### Option 4 Correct
$\frac{4}{28} = \frac{x}{63}$

##### Explanation
The proportion must maintain consistent unit relationships on both sides. Since 4 interviewers complete 28 interviews, and we need to find how many interviewers ($x$) are needed for 63 interviews, the proportion is: $\frac{4 \text{ interviewers}}{28 \text{ interviews}} = \frac{x \text{ interviewers}}{63 \text{ interviews}}$, which gives $\frac{4}{28} = \frac{x}{63}$. This setup ensures that both ratios compare interviewers to interviews in the same way.

##### Distractors

###### Option 1
Inverts the second ratio by placing $63$ in the numerator and $x$ in the denominator. This creates an inconsistent relationship where one side is $\text{interviewers}/\text{interviews}$ and the other is $\text{interviews}/\text{interviewers}$.

###### Option 2
Creates a unit inconsistency by setting the ratio of $\text{interviews}/\text{interviewers}$ equal to $\text{interviewers}/\text{interviews}$ ($\frac{28}{4} = \frac{x}{63}$). This setup fails to maintain parallel unit structures.

###### Option 3
Reverses the interviews ratio ($\frac{4}{x} = \frac{63}{28}$) for a direct variation problem. This would incorrectly imply that as the number of interviews increases, the number of interviewers needed should decrease.
