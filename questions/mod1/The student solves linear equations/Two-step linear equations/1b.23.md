##### Explanation
This problem requires solving the two-step linear equation $40p + 200 = 1000$, where $p$ represents the number of products sold. First, subtract the base salary from both sides: $40p = 1000 - 200 = 800$. Then, divide both sides by the commission rate: $p = 800 \div 40 = 20$ products.

##### Distractors

###### Option 1
Divides total goal by base salary instead of commission rate. The candidate calculates $1000 \div 200 = 5$, confusing which value represents the per-unit rate. This error reflects misunderstanding of the equation structure, using the fixed constant as the divisor rather than the coefficient of the variable.

###### Option 3
Omits the first step of subtracting the base salary. The candidate calculates $1000 \div 40 = 25$, dividing the total directly by the commission rate without first isolating the variable term. This is the most common error in two-step equations, where candidates skip subtracting the constant before dividing.

###### Option 4
Adds the base salary instead of subtracting it. The candidate calculates $(1000 + 200) \div 40 = 1200 \div 40 = 30$, applying the inverse operation. This error occurs when candidates recognize that two operations are needed but select the wrong operation for the first step, adding rather than subtracting to isolate the variable term.
