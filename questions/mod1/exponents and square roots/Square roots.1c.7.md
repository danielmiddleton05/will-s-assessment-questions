##### Explanation
The width of each square banner equals the square root of its area. The first banner has a width of $\sqrt{36} = 6$ feet, and the second has a width of $\sqrt{64} = 8$ feet. The combined width is $6 + 8 = 14$ feet. This question assesses the ability to simplify square root expressions and correctly combine them, while also testing the common misconception that $\sqrt{a + b} = \sqrt{a} + \sqrt{b}$.

##### Distractors
###### Option 1
$10$ feet — Adds areas before taking the square root. Student computes $\sqrt{36 + 64} = \sqrt{100} = 10$, applying the misconception that $\sqrt{a + b} = \sqrt{a} + \sqrt{b}$. This is a well-documented algebraic error where students incorrectly distribute the radical over addition.

###### Option 2
$12$ feet — Uses only the smaller banner's area for both. Student correctly computes $\sqrt{36} = 6$, then multiplies by $2$ because there are two banners, arriving at $6 \times 2 = 12$. This error reflects a misreading of the problem in which the student assumes both banners have the same area rather than computing each square root independently.

###### Option 4
$16$ feet — Uses only the larger banner's area for both. Student correctly computes $\sqrt{64} = 8$, then multiplies by $2$ because there are two banners, arriving at $8 \times 2 = 16$. The student overlooks that the two banners have different areas and defaults to the more prominent or last-mentioned value.
