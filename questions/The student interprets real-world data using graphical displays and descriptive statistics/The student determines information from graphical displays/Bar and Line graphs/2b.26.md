##### Explanation
To find the percent decrease from March to April, first read the revenue values from the line graph: March is $70,000 and April is $50,000. The decrease in revenue is $70,000 − $50,000 = $20,000. The percent decrease is calculated as (decrease ÷ original value) × 100 = ($20,000 ÷ $70,000) × 100 ≈ 28.6%. This requires both accurately reading values from the graph and applying the percent change formula using the original (March) value as the denominator.

##### Distractors
###### Option 1
A candidate might arrive at 22.2% by incorrectly using the sum of the two months' revenues as the denominator rather than the original month alone—computing $20,000 ÷ ($70,000 + $50,000) × 100 ≈ 16.7% or a similar erroneous base—or by misreading one of the values from the graph (e.g., reading March as $65,000 instead of $70,000 and then computing $15,000 ÷ $65,000 ≈ 23.1%, which rounds in the neighborhood of 22.2%). This reflects a misunderstanding of which value serves as the base in a percent decrease calculation.

###### Option 2
A candidate might select 25.7% by mistakenly using a value between the correct base and an incorrect base, such as averaging the March and April values to get $60,000 and computing $20,000 ÷ $60,000 × 100 ≈ 33.3%, or by slight misreading of graph values. This option is close enough to the correct answer to attract candidates who set up the calculation correctly but make a minor arithmetic or reading error.

###### Option 4
A candidate might arrive at 40.0% by using the April value ($50,000) as the denominator instead of the March value ($70,000), computing $20,000 ÷ $50,000 × 100 = 40.0%. This is a common error in percent change problems where a student divides by the new value rather than the original value, reflecting a misunderstanding of the percent decrease formula.
