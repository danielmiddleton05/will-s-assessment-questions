**Given:** A site reliability team ran three load tests against the same web service and recorded the response times in milliseconds (ms).

- **Test A:** 215, 230, 235, 235, 220, 225  
- **Test B:** 405, 395, 410, 420, 415, 398  
- **Test C:** 150, 170, 165, 180, 160, 175  

How should these three tests be ranked by **range** from **largest to smallest**?

##### Explanation
Compute each range using maximum minus minimum.

- Test A: max 235, min 215 → range = 20  
- Test B: max 420, min 395 → range = 25  
- Test C: max 180, min 150 → range = 30  

Rank by range (largest to smallest): Test C (30), Test B (25), Test A (20).  
**Correct order: Test C, Test B, Test A.**

##### Distractors

###### Option 1

###### Option 2

###### Option 4
