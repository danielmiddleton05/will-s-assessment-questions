##### Explanation
An outlier is a data point that is significantly separated from the rest of the data. The histogram shows a tight cluster of download speeds between 70 and 120 Mbps, with 39 of the 40 computers falling in that range. One computer recorded a speed near 15 Mbps, and there is a wide gap of empty bins (20–70 Mbps) between this single bar and the main cluster. This large gap makes the 15 Mbps reading a clear outlier. The correct answer (Option 3) identifies both the isolated value and the gap that defines it as an outlier.

##### Distractors
###### Option 1
"The most frequently recorded download speed is approximately 15 Mbps." — This confuses the outlier with the mode. The 15 Mbps value appears only once (the least frequent), while speeds near 90–100 Mbps are the most common. Students may mistakenly associate a visually distinctive data point with the most frequent value.

###### Option 2
"The highest recorded speed is an outlier because it appears at the upper edge of the data." — This confuses the upper boundary of the main cluster with an outlier. While 120 Mbps is at the high end, it sits within the main cluster with no gap separating it from neighboring values. Students may incorrectly assume that any extreme value within a cluster qualifies as an outlier.

###### Option 4
"The distribution of download speeds is skewed to the right because the data is clustered at the higher end of the scale." — This represents a common misunderstanding of skewness. A student might incorrectly assume "skewed to the right" means the majority of the data is on the right side of the graph, when skewness actually refers to the direction of the tail. Because the outlier and the resulting tail are on the left, this distribution is actually skewed to the left.

```python
import matplotlib.pyplot as plt
import numpy as np

def setup_style():
    """Configure matplotlib style to match scientific plotting standards."""
    plt.rcParams['font.family'] = 'DejaVu Sans'
    plt.rcParams['font.size'] = 10
    plt.rcParams['axes.titlesize'] = 14
    plt.rcParams['axes.titleweight'] = 'bold'
    plt.rcParams['axes.labelsize'] = 12
    plt.rcParams['axes.labelcolor'] = '#333333'
    plt.rcParams['xtick.labelsize'] = 10
    plt.rcParams['ytick.labelsize'] = 10
    plt.rcParams['xtick.color'] = '#666666'
    plt.rcParams['ytick.color'] = '#666666'
    plt.rcParams['axes.edgecolor'] = '#333333'
    plt.rcParams['axes.linewidth'] = 1.0
    plt.rcParams['grid.color'] = '#CCCCCC'
    plt.rcParams['grid.linewidth'] = 0.5
    plt.rcParams['figure.facecolor'] = 'white'
    plt.rcParams['axes.facecolor'] = 'white'

def plot_image():
    """Generate the scientific visualization."""
    setup_style()

    fig, ax = plt.subplots(figsize=(10.24, 10.24))

    # Hide top and right spines
    ax.spines['top'].set_visible(False)
    ax.spines['right'].set_visible(False)

    # Data definition
    # Bin start locations (left edges) and their corresponding heights
    bin_starts = np.array([10, 70, 80, 90, 100, 110])
    counts = np.array([1, 5, 12, 14, 6, 2])
    bin_width = 10

    # Plot the histogram bars
    # align='edge' places the bar starting at x, extending to x+width
    ax.bar(bin_starts, counts, width=bin_width, align='edge',
           color='#1f77b4', edgecolor='black', linewidth=1.0)

    # Configure X-axis
    ax.set_xlim(0, 130)
    ax.set_xticks(np.arange(0, 131, 10))
    ax.set_xlabel('Download Speed (Mbps)')

    # Configure Y-axis
    ax.set_ylim(0, 16)
    ax.set_yticks(np.arange(0, 17, 2))
    ax.set_ylabel('Number of Computers')

    # Add Title
    ax.set_title('Office Download Speed Test Results', pad=15, color='#333333')

    # Configure Grid
    ax.yaxis.grid(True)     # Horizontal grid lines only
    ax.xaxis.grid(False)
    ax.set_axisbelow(True)  # Grid behind the bars

    # Tick Styling
    ax.tick_params(direction='out', length=6, width=1)

    plt.tight_layout()
    return fig

if __name__ == "__main__":
    fig = plot_image()
    plt.savefig('plot.png', dpi=150, bbox_inches='tight')
    print("Image saved as plot.png")
```
