##### Aligned Content

##### Domain

##### Explanation
The starting user count plus all gains minus the unknown loss must equal the ending count: 1,250 + 185 − x + 130 = 940. Combining the known values gives 1,565 − x = 940, so x = 1,565 − 940 = 625. The server problem caused the loss of 625 users. This question assesses the ability to apply integer operations with positive and negative values by working backward from a known result to find a missing value. ##### Distractors

###### Option 3
525 users — The student sets up the problem correctly but makes a carrying error when adding 1,250 + 185, getting 1,335 instead of 1,435 (forgetting to carry from the tens to the hundreds column), then computes 1,335 + 130 − 940 = 525. This targets students who understand the problem structure but make an arithmetic mistake in multi-step computation.
