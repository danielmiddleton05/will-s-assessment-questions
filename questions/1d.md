### Task: wgu_a1ds1_Cybersecurity Threat Score Calculation_r7Km3

#### Task Description

Given: A cybersecurity team calculates a threat score for system vulnerabilities using this formula:

$$
\text{Threat Score} = (\text{Exploitability rating} \times \text{Impact rating}) \div \text{Number of active defenses}
$$

For a flagged vulnerability, the exploitability rating is $9$, the impact rating is $0$ because the vulnerability does not affect the current system configuration, and the number of active defenses is $3$.

What is the threat score for this vulnerability?

#### Quiz Options

###### Option 1 Correct
0


###### Option 2 Incorrect
3


###### Option 3 Incorrect
9


###### Option 4 Incorrect
Undefined


#### Quiz Settings

```json
{
  "shuffleOptions": false,
  "multipleChoice": false,
  "hasNoneOfTheAbove": false
}
```


#### Internal Notes

##### Competency
The student applies quantitative operations to solve real-world problems.

##### Evidence Statement
The student applies number sense to expressions.

##### Aligned Content
Zero in multiplication/division

##### Domain
Technology

##### Explanation
The threat score is $(9 \times 0) \div 3$. First, $9 \times 0 = 0$ because any number multiplied by zero equals zero. Then, $0 \div 3 = 0$ because zero divided by any non-zero number equals zero. Unlike the original question, which tests a single division operation with zero as the numerator, this variation requires multi-step reasoning: the student must first evaluate a product involving zero and then carry that result through a division. This assesses understanding of how zero behaves across both multiplication and division in a practical cybersecurity vulnerability scoring context.

##### Distractors
###### Option 2
3 — The student computes $9 \div 3 = 3$, effectively skipping the multiplication step or treating the impact rating of 0 as though it has no effect on the calculation. This error reflects a failure to recognize that multiplying by zero makes the entire product zero, regardless of the other factor's value.

###### Option 3
9 — The student selects only the exploitability rating, treating the impact rating of 0 as though it were 1 (the multiplicative identity) and also ignoring the division by 3. This reflects a misunderstanding of the zero property of multiplication, where the student may believe that multiplying by zero "does nothing" to the original number.

###### Option 4
Undefined — The student sees zero in the formula and incorrectly concludes the entire expression is undefined. This confuses zero appearing as a factor in the numerator (which produces a valid result of zero) with zero appearing as a divisor (which would be undefined). Students may recall that "zero causes problems in calculations" without understanding that the issue only arises when zero is the divisor.

### Task: wgu_a1ds2_Classifying Irrational Number Expressions_r7Km3

#### Task Description

A warehouse manager calculates that a square storage section has an area of 50 square feet. To order baseboard trim for all four walls, the manager needs to know the length of each side, which equals $\sqrt{50}$ feet.

What correctly explains whether $\sqrt{50}$ is rational or irrational?

#### Quiz Options

###### Option 1 Incorrect
Rational, because $\sqrt{50}$ simplifies to $5\sqrt{2}$, which is a product of integers.


###### Option 2 Incorrect
Rational, because $\sqrt{50}$ simplifies to $\frac{50}{2}$, which equals the integer 25.


###### Option 3 Correct
Irrational, because $\sqrt{50}$ cannot be expressed as a ratio of two integers.


###### Option 4 Incorrect
Irrational, because the square root symbol in the expression indicates the result is irrational.


#### Quiz Settings

```json
{
  "shuffleOptions": false,
  "multipleChoice": false,
  "hasNoneOfTheAbove": false
}
```


#### Internal Notes

##### Competency
The student applies quantitative operations to solve real-world problems.

##### Evidence Statement
The student applies number sense to expressions.

##### Aligned Content
Rational & real numbers

##### Domain
Business

##### Explanation
$\sqrt{50}$ simplifies to $5\sqrt{2}$. Since $\sqrt{2}$ is irrational—it cannot be expressed as a ratio of two integers—and the product of a nonzero integer and an irrational number is irrational, $\sqrt{50}$ is also irrational. Option 3 correctly identifies this classification and provides valid reasoning. Option 1 correctly simplifies $\sqrt{50}$ to $5\sqrt{2}$ but erroneously calls it "a product of integers," treating $\sqrt{2}$ as though it equals the integer 2. Option 2 confuses the square root operation with dividing by 2, incorrectly claiming that $\sqrt{50} = \frac{50}{2} = 25$. Option 4 arrives at the correct classification but uses flawed reasoning, since square roots of perfect squares (e.g., $\sqrt{4} = 2$, $\sqrt{9} = 3$) are rational.

##### Distractors
###### Option 1
Misinterprets the simplified form $5\sqrt{2}$ as a product of two integers (5 and 2), concluding the result is rational. Students making this error either confuse $\sqrt{2}$ with 2 or believe that because both 5 and the radicand 2 are integers, the entire expression must be rational. They do not recognize that $\sqrt{2}$ is irrational and that multiplying it by an integer preserves its irrationality.

###### Option 2
Confuses the square root operation with dividing by 2, concluding that $\sqrt{50} = \frac{50}{2} = 25$, which is an integer and therefore rational. Students making this error do not understand the definition of a square root—finding a number that, when multiplied by itself, yields the radicand—and instead apply an incorrect arithmetic operation to the radicand.

###### Option 4
Reaches the correct classification (irrational) but relies on the false generalization that the square root symbol itself signals irrationality. This reasoning fails for perfect squares such as $\sqrt{25} = 5$ or $\sqrt{64} = 8$. Students selecting this option associate the radical symbol with irrationality rather than evaluating whether the radicand is a perfect square.

### Task: wgu_a1ds3_Exponential Infection Case Growth_r7mK3

#### Task Description

A laboratory technician is monitoring a bacterial culture for a medical study. At 10:00 AM, the culture contains 40 bacteria. The population is observed to double every hour. 

How many bacteria will be in the culture at 3:00 PM?

#### Quiz Options

###### Option 1 Incorrect
400


###### Option 2 Incorrect
640


###### Option 3 Correct
1,280


###### Option 4 Incorrect
2,560


#### Quiz Settings

```json
{
  "shuffleOptions": false,
  "multipleChoice": false,
  "hasNoneOfTheAbove": false
}
```


#### Internal Notes

##### Competency
The student applies quantitative operations to solve real-world problems.

##### Evidence Statement
The student simplifies expressions with exponents and square roots.

##### Aligned Content
Exponents

##### Domain
Healthcare

##### Explanation
This question assesses the ability to model a real-world exponential growth scenario and evaluate the resulting expression. The student must recognize that from 10:00 AM to 3:00 PM there are 5 growth intervals, meaning the bacteria count at 3:00 PM is $40 \times 2^5$. Evaluate the exponent: $2^5 = 2 \times 2 \times 2 \times 2 \times 2 = 32$. Then multiply: $40 \times 32 = 1,280$. The correct answer is 1,280.

##### Distractors
###### Option 1
400 — Targets students who multiply the base by the exponent ($2 \times 5 = 10$) instead of evaluating $2^5 = 32$, then compute $40 \times 10 = 400$.

###### Option 2
640 — Targets students who miscount the number of growth intervals, using an exponent of 4 instead of 5 (effectively calculating the 2:00 PM count), computing $40 \times 2^4 = 40 \times 16 = 640$.

###### Option 4
2,560 — Targets students who use 6 as the exponent because 3:00 PM is the 6th timestamp in the sequence (10, 11, 12, 1, 2, 3), computing $40 \times 2^6 = 40 \times 64 = 2,560$, instead of recognizing that only 5 growth intervals occur.

### Task: wgu_a1ds4_Business Profit Inequality Solution_r7Mn3

#### Task Description

**Given:** A small business earns 18 US dollars in revenue per unit sold and has fixed monthly costs of 540 US dollars. Monthly profit is calculated as total revenue minus fixed costs.

What solution set represents the number of units that must be sold each month for the business to earn a positive profit?

#### Quiz Options

###### Option 1 Incorrect
$[30, \infty)$


###### Option 2 Correct
$(30, \infty)$


###### Option 3 Incorrect
$[540, \infty)$


###### Option 4 Incorrect
$(540, \infty)$


#### Quiz Settings

```json
{
  "shuffleOptions": false,
  "multipleChoice": false,
  "hasNoneOfTheAbove": false
}
```


#### Internal Notes

##### Competency
The student applies quantitative operations to solve real-world problems.

##### Evidence Statement
The student solves and graphs linear inequalities.

##### Aligned Content
Representing solution sets

##### Domain
Business

##### Explanation
Monthly profit is modeled as $P = 18x - 540$, where $x$ is the number of units sold. For a positive profit, the inequality is $18x - 540 > 0$. Solving: $18x > 540$, so $x > 30$. Because the inequality is strict (profit must be greater than zero, not equal to zero), the endpoint 30 is excluded, which is shown with a parenthesis. The solution set extending to the right without bound is represented as $(30, \infty)$.

##### Distractors
###### Option 1
$[30, \infty)$ — This distractor is intentionally designed to assess whether the student distinguishes between strict and inclusive inequality notation, a core skill within the evidence statement. At $x = 30$, profit equals $18(30) - 540 = 0$, which is not a positive profit. A student choosing this option solved the algebra correctly but misinterpreted the problem condition: the prompt requires strictly positive profit ($P > 0$, yielding $x > 30$ with an excluded endpoint), not non-negative profit ($P \geq 0$, which would include 30). Confusing "greater than" with "greater than or equal to" when translating word problems into interval notation is a well-documented common error that this distractor deliberately targets.

###### Option 3
$[540, \infty)$ — This combines two errors: using the fixed cost value of 540 directly as the boundary rather than dividing both sides by 18, and including the endpoint with a square bracket rather than excluding it with a parenthesis.

###### Option 4
$(540, \infty)$ — This uses the fixed cost value of 540 directly as the boundary rather than solving the inequality. A student choosing this option likely recognized that the number of units must exceed some threshold but skipped the algebraic step of dividing both sides by 18.
