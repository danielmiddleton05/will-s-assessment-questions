A data center manager has $48$ processing units and $36$ cooling modules to distribute evenly into identical server racks, with no components left over. Each rack must contain the same number of processing units and the same number of cooling modules.

What is the greatest number of identical server racks that can be assembled?

##### Explanation
To determine the greatest number of identical server racks, we need to find the Greatest Common Factor (GCF) of $48$ and $36$. Using prime factorization: $48 = 2^4 \times 3$ and $36 = 2^2 \times 3^2$. The GCF takes the lowest power of each shared prime factor: $\text{GCF} = 2^2 \times 3 = 4 \times 3 = 12$. Therefore, the manager can assemble $12$ identical server racks, each containing $4$ processing units and $3$ cooling modules.
