#### Task Description

**Given:** A statistician is analyzing data collection costs for a research project. The data shows that collecting 50 survey responses costs $30, and collecting 100 survey responses costs $60.

If $r$ represents the number of survey responses and $c$ represents the cost in dollars, what equation correctly models this proportional relationship?

#### Quiz Options

###### Option 1 Incorrect
$c = 0.3r$


###### Option 2 Correct
$c = 0.6r$


###### Option 3 Incorrect
$c = 1.67r$


###### Option 4 Incorrect
$c = 30r$

##### Explanation
To find the constant of proportionality, divide the cost by the number of responses: \$30 $\div$ 50 responses = \$0.60 per response. Therefore, the equation is $c = 0.6r$. Verification: \$0.60 $\times$ 100 = \$60, confirming the cost is \$60.

##### Distractors
###### Option 1
$c = 0.3r$ — Mixes up data points in calculation
The student divides \$30 by 100 responses instead of by 50 responses, getting \$0.30 per response. This error mismatches the cost with the wrong number of responses and would underestimate costs (e.g., predicting \$30 for 100 responses instead of \$60).

###### Option 3
$c = 1.67r$ — Inverts the ratio calculation
The student calculates $50 \div 30 \approx 1.67$, dividing responses by cost instead of cost by responses to find the rate. This reverses the relationship and would overestimate costs (e.g., predicting \$167 for $100$ responses instead of \$60).

###### Option 4
$c = 30r$ — Uses total cost instead of unit rate
The student incorrectly uses \$30 as the multiplier, confusing the total cost for one data point with the per-unit rate. This would result in dramatically overestimating costs (e.g., predicting \$3,000 for $100$ responses instead of \$60).
