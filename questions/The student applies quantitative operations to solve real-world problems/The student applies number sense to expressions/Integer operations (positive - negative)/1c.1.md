#### Task Description

An app had 1,250 users at the start of a 3-month period. During that time, three things happened: an update brought in 185 new users, a server problem caused an unknown number of users to leave, and advertising brought in 130 new users. At the end of the 3 months, the app had 940 users.

How many users left because of the server problem?

###### Option 1 Incorrect

###### Option 2 Incorrect
495 users


###### Option 3 Incorrect
525 users


###### Option 4 Correct

##### Explanation
The starting user count plus all gains minus the unknown loss must equal the ending count: 1,250 + 185 − x + 130 = 940. Combining the known values gives 1,565 − x = 940, so x = 1,565 − 940 = 625. The server problem caused the loss of 625 users. This question assesses the ability to apply integer operations with positive and negative values by working backward from a known result to find a missing value. It requires identifying which amounts are gains (additions) and which are losses (subtractions) and performing accurate multi-step arithmetic.

##### Distractors
###### Option 1
440 users — The student omits the update gain of 185, computing 1,250 + 130 − 940 = 440. This targets students who lose track of one step in a multi-step problem, accounting for only the advertising gain and not the update gain.

###### Option 2
495 users — The student omits the advertising gain from the equation (1,250 + 185 − 940 = 495). This targets students who lose track of one step in a multi-step problem, solving with only one of the two gains.

###### Option 3
525 users — The student sets up the problem correctly but makes a carrying error when adding 1,250 + 185, getting 1,335 instead of 1,435 (forgetting to carry from the tens to the hundreds column), then computes 1,335 + 130 − 940 = 525. This targets students who understand the problem structure but make an arithmetic mistake in multi-step computation.
