#### Task Description

A teacher calculates final grades using the weighted expression $0.4t + 0.3p + 0.3f$, where $t$ represents the test average, $p$ represents the project score, and $f$ represents the final exam score.

If a student has a test average of 80, a project score of 90, and a final exam score of 70, what is the student's final grade?

##### Explanation
To find the final grade, substitute the given values into the expression: $0.4(80) + 0.3(90) + 0.3(70) = 32 + 27 + 21 = 80$. The student must correctly apply the weighted coefficients to each score and sum the results.

##### Distractors
###### Option 1
78 — Results from miscalculating one of the weighted terms. A student might compute $0.4(80)$ incorrectly as 30 instead of 32, yielding $30 + 27 + 21 = 78$. Alternatively, the student might incorrectly calculate $0.3(70)$ as 19 instead of 21, resulting in $32 + 27 + 19 = 78$.

###### Option 2
79 — Results from swapping the test average and final exam scores when substituting into the expression. A student computing $0.4(70) + 0.3(90) + 0.3(80) = 28 + 27 + 24 = 79$ incorrectly uses 70 for the test average and 80 for the final exam score. This targets students who confuse which value corresponds to which variable in the expression.

###### Option 4
81 — Results from reversing the weights for test and project scores. A student computing $0.3(80) + 0.4(90) + 0.3(70) = 24 + 36 + 21 = 81$ incorrectly applies the 40% weight to the project and the 30% weight to the test average. This targets students who confuse which weight applies to which variable.
