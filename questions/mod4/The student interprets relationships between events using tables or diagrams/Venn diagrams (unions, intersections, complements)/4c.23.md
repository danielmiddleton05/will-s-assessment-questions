#### Task Description

**Given:** A cybersecurity team logged the types of security alerts triggered on 150 company devices over one month. The results are summarized in the table below.

| | Malware Alert Triggered | No Malware Alert | Total |
|---|---|---|---|
| **Phishing Alert Triggered** | 18 | 42 | 60 |
| **No Phishing Alert** | 32 | 58 | 90 |
| **Total** | 50 | 100 | 150 |

If this data were displayed in a Venn diagram with one circle for devices that triggered a malware alert and another circle for devices that triggered a phishing alert, as shown below, how many devices would be located in the overlapping region of both circles?

##### Explanation
In a Venn diagram, the overlapping region of two circles represents the intersection of the two events—devices that triggered both a malware alert and a phishing alert. Reading the two-way table, the cell where "Malware Alert Triggered" and "Phishing Alert Triggered" intersect contains the value 18. This is the number of devices that belong in the overlapping region. Translating between a two-way table and a Venn diagram is a fundamental skill in probability and set theory; the cell where both row and column conditions are met corresponds to the intersection region where both circles overlap.

##### Distractors

In the Venn diagram, 42 represents devices inside only the Phishing Alert circle (phishing alert but no malware alert), not the overlapping region.

This targets students who recognize that the overlap involves malware alerts but read the total number of devices with a malware alert instead of narrowing to only those that also triggered a phishing alert. In the Venn diagram, 50 represents the entire Malware Alert circle (both the overlap and the malware-only region combined).

```python
import matplotlib.pyplot as plt
import matplotlib.patches as patches
import numpy as np

def setup_style():
    """Configure matplotlib style to match scientific plotting standards."""
    plt.rcParams['font.family'] = 'DejaVu Sans'
    plt.rcParams['font.size'] = 10
    plt.rcParams['axes.titlesize'] = 14
    plt.rcParams['axes.titleweight'] = 'bold'
    plt.rcParams['axes.labelsize'] = 12
    plt.rcParams['axes.labelcolor'] = '#333333'
    plt.rcParams['xtick.labelsize'] = 10
    plt.rcParams['ytick.labelsize'] = 10
    plt.rcParams['xtick.color'] = '#666666'
    plt.rcParams['ytick.color'] = '#666666'
    plt.rcParams['axes.edgecolor'] = '#333333'
    plt.rcParams['axes.linewidth'] = 1.0
    plt.rcParams['grid.color'] = '#CCCCCC'
    plt.rcParams['grid.linewidth'] = 0.5
    plt.rcParams['figure.facecolor'] = 'white'
    plt.rcParams['axes.facecolor'] = 'white'

def plot_image():
    """Generate the scientific Venn diagram visualization."""
    setup_style()

    # Create figure and axis
    fig, ax = plt.subplots(figsize=(10.24, 10.24))

    # Set coordinate system for easier placement
    ax.set_xlim(0, 10)
    ax.set_ylim(0, 10)
    ax.set_aspect('equal')
    
    # Hide standard axes elements (ticks, spines) since this is a diagram
    ax.axis('off')

    # Define colors
    blue_color = '#1f77b4'
    orange_color = '#ff7f0e'
    text_color = '#333333'

    # Draw the Universal Set (Rectangular Frame)
    # Positioning a large rectangle centered in the plot
    rect = patches.Rectangle((0.5, 1.5), 9, 7, 
                             linewidth=1.5, 
                             edgecolor='black', 
                             facecolor='none',
                             zorder=1)
    ax.add_patch(rect)

    # Circle parameters
    radius = 2.2
    y_center = 5.0
    x_offset = 1.5  # Offset from center x=5
    
    # Left Circle (Malware Alert)
    circle_left = patches.Circle((5 - x_offset, y_center), radius, 
                                 linewidth=1.5, 
                                 edgecolor=blue_color, 
                                 facecolor=blue_color, 
                                 alpha=0.2, 
                                 zorder=2)
    # Add border again to ensure it's not transparent like the face
    circle_left_border = patches.Circle((5 - x_offset, y_center), radius, 
                                        linewidth=1.5, 
                                        edgecolor=blue_color, 
                                        facecolor='none', 
                                        zorder=3)
    
    ax.add_patch(circle_left)
    ax.add_patch(circle_left_border)

    # Right Circle (Phishing Alert)
    circle_right = patches.Circle((5 + x_offset, y_center), radius, 
                                  linewidth=1.5, 
                                  edgecolor=orange_color, 
                                  facecolor=orange_color, 
                                  alpha=0.2, 
                                  zorder=2)
    # Add border again for opacity
    circle_right_border = patches.Circle((5 + x_offset, y_center), radius, 
                                         linewidth=1.5, 
                                         edgecolor=orange_color, 
                                         facecolor='none', 
                                         zorder=3)
    
    ax.add_patch(circle_right)
    ax.add_patch(circle_right_border)

    # Add Labels
    # Malware Alert Label (Left)
    ax.text(5 - x_offset, y_center + radius + 0.4, "Malware Alert", 
            ha='center', va='bottom', 
            fontsize=14, color=text_color, fontweight='normal')

    # Phishing Alert Label (Right)
    ax.text(5 + x_offset, y_center + radius + 0.4, "Phishing Alert", 
            ha='center', va='bottom', 
            fontsize=14, color=text_color, fontweight='normal')

    plt.tight_layout()
    return fig

if __name__ == "__main__":
    fig = plot_image()
    plt.savefig('plot.png', dpi=150, bbox_inches='tight')
    print("Image saved as plot.png")
```
