#### Task Description

**Given:** A data center monitors server performance. Server A failed 8 times in 400 operating days. Server B failed 12 times in 400 operating days. Server C failed 8 times in 200 operating days.

Which server has the highest probability of failure on any given operating day?

##### Explanation
Probability is calculated as failures divided by operating days. Server A: $8/400 = 0.02$. Server B: $12/400 = 0.03$. Server C: $8/200 = 0.04$. Server C has the highest probability of failure at 0.04 (4% daily failure rate).

##### Distractors

###### Option 1
Targets students who may perform calculation errors or who incorrectly reason that a higher number of operating days results in a higher probability of failure, without properly accounting for the rate calculation.

###### Option 2
Targets students who compare absolute failure counts without accounting for the number of operating days, missing that probability requires considering both the number of failures and the number of opportunities for failure.

###### Option 4
Targets students who match the failure counts of 8 for A and C and assume they are equally likely, while also incorrectly concluding this represents a higher probability than Server B's rate.
