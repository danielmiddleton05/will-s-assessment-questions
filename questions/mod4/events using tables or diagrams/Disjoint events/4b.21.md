#### Task Description

**Given:** A statistician analyzes customer service data for a retail company. The data shows complaints categorized as follows in the table below:

| Complaint Type | Count |
|---------------|-------|
| Billing issues | 145 |
| Product defects | 203 |
| Delivery delays | 127 |

Each complaint is assigned to exactly one category.

What statistical term describes the relationship between these three complaint categories?

##### Explanation
Mutually exclusive (or disjoint) events cannot occur simultaneously. In this scenario, a complaint classified as a billing issue cannot simultaneously be classified as a product defect or delivery delay. Since each complaint belongs to exactly one category, these events are mutually exclusive. The table demonstrates this clearly: the categories partition all complaints into distinct, non-overlapping groups.

##### Distractors

###### Option 1
Independent events — Confuses mutual exclusivity with independence
Students may select this if they confuse events that cannot occur together (mutually exclusive) with events whose occurrence does not affect each other's probability (independent). In fact, mutually exclusive events are dependent because knowing one occurred means the others cannot occur.

###### Option 2
Conditional events — Confuses exclusivity with conditional probability
Students may select this if they think the classification process implies conditional probability relationships. Conditional events involve probabilities that change based on given information, which is different from the structural relationship of mutual exclusivity shown in the table.

###### Option 3
Complementary events — Confuses mutual exclusivity with complement
Students may select this if they believe mutually exclusive events with multiple categories are complements. However, complementary events specifically refer to exactly two outcomes: an event and its opposite (occurring or not occurring), not three or more mutually exclusive categories.
