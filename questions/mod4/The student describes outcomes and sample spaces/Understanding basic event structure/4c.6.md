#### Task Description

**Given:** A cloud storage provider monitors daily backup processes. Each day, the system records whether the backup completed without errors. Over a 60-day period, backups completed without errors on 54 of those days.

What qualifies as an event in this scenario?

#### Quiz Options

###### Option 1 Incorrect
Each daily backup process that the system records.


###### Option 2 Correct
A backup completing without errors on a given day.


###### Option 3 Incorrect
All possible results of a daily backup, such as completing with or without errors.


###### Option 4 Incorrect
The ratio of 54 error-free backups out of 60 total days.

##### Explanation
An event in probability is a specific outcome or set of outcomes of interest. In this scenario, "a backup completing without errors on a given day" describes a particular condition that either occurs or does not on each day — making it the event. Each daily backup process is a trial (a single repetition of the experiment). All possible results (success or failure) make up the sample space. The ratio $\frac{54}{60}$ is the probability of the event, not the event itself. This question requires the student to evaluate four distinct scenario elements and determine which one fits the definition of an event, rather than simply labeling a pre-identified element.

##### Distractors
###### Option 1
Each daily backup process that the system records — Confuses event with trial

This targets students who mistake the act of conducting the experiment (each day's backup check) for the specific outcome of interest. Each daily backup is a trial — a single repetition of the observation — not the event itself.

###### Option 3
All possible results of a daily backup, such as completing with or without errors — Confuses event with sample space

This targets students who do not distinguish between the full set of possible outcomes (the sample space, which includes both success and failure) and a specific subset of interest (the event, which focuses only on error-free completion).

###### Option 4
The ratio of 54 error-free backups out of 60 total days — Confuses event with probability

This targets students who conflate a described condition with its numerical likelihood. The ratio $\frac{54}{60}$ quantifies how often the event occurred and represents the probability, but the event itself is the condition of completing without errors.
