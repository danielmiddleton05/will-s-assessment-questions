#### Task Description

**Given:** A data center runs an automated backup every night. Each backup produces one of three statuses: "complete," "partial," or "failed."

What does the set {$\text{complete, partial, failed}$} represent within the probability structure of a single nightly backup?

##### Explanation
The sample space is the complete set of all possible outcomes of a probability experiment. For a single nightly backup, the three possible results are "complete," "partial," and "failed." Because $\{\text{complete, partial, failed}\}$ exhaustively lists every result that could occur from one backup, it is the sample space. An event is a subset of the sample space (e.g., $\{\text{partial, failed}\}$ might represent the event "the backup did not fully succeed"). A trial is the act of performing the experiment—in this case, running one nightly backup—not the list of possible results. A probability distribution would assign a numerical probability to each outcome, but the given set contains only labels with no associated likelihoods.

##### Distractors
###### Option 2
"It is an event because it describes a collection of outcomes that could occur" — Confuses an event with the sample space. While an event is indeed a set of outcomes, the defining feature of the sample space is that it contains all possible outcomes. A student who does not distinguish between a proper subset and the full set of outcomes may select this option.

###### Option 3
"It is a trial because it represents three separate attempts at backing up data" — Confuses three listed outcomes with three separate attempts. A trial is the single act of performing the experiment (running one backup), not the enumeration of its possible results. A student who misreads the three statuses as three repetitions of the process may find this plausible.

###### Option 4
"It is a probability distribution because it identifies how likely each status is to occur" — Confuses a sample space with a probability distribution. A probability distribution assigns a numerical likelihood to each outcome; the given set merely names the outcomes without any associated probabilities. A student who conflates listing outcomes with quantifying their chances may choose this option.
