##### Explanation
In a probability tree, a single outcome in the sample space is a complete path from the root to a terminal branch. Each path traces the full sequence of stages a patient moves through—first a classification (critical or stable), then a placement (such as ICU, surgical unit, observation, or discharged home). Therefore, an outcome is described as the entire pathway, such as "critical and then ICU," not just one stage or a numerical likelihood.

##### Distractors
###### Option 1
A single classification, such as "critical," identifying only the initial category a patient receives — Confuses the first branch with a complete outcome. This targets students who think the first decision point alone constitutes an outcome, overlooking that the tree continues to a second stage and an outcome must trace through all stages.

###### Option 2
The entire set of final destinations, such as "ICU, Surgical Unit, Observation, and Discharged Home," representing every possible result — Confuses a single outcome with the entire sample space. This targets students who recognize the potential endpoints but provide the collection of all possible results rather than a single, specific pathway.

###### Option 4
A probability value, such as "40%," measuring the chance of a patient reaching a given unit — Confuses an outcome with its probability. This targets students who conflate what can happen (an outcome) with how likely it is to happen (a probability), which are fundamentally different concepts in probability.

    plt.rcParams['font.family'] = 'DejaVu Sans'

    plt.rcParams['axes.titlesize'] = 14

def draw_node(ax, text, center, box_style):
    """Draw a node with a text label and a bounding box."""
    x, y = center
    ax.text(x, y, text,
            ha='center', va='center',
            color='#333333',
            fontsize=12,
            bbox=box_style,
            zorder=10) # High zorder to stay on top of lines

def draw_link(ax, start, end):
    """Draw a connecting line between two points."""
    x_start, y_start = start
    x_end, y_end = end
    ax.plot([x_start, x_end], [y_start, y_end], 
            color='#333333', linewidth=1.5, zorder=1)

def plot_image():
    """Generate the scientific visualization."""
    setup_style()

    fig, ax = plt.subplots(figsize=(10.24, 10.24))

    # Disable axes for diagram
    ax.axis('off')
    
    # Set plot limits to ensure margins
    ax.set_xlim(0, 1.0)
    ax.set_ylim(0, 1.0)

    # Define Node Coordinates
    # Level 0
    root_pos = (0.15, 0.5)
    
    # Level 1
    l1_top_pos = (0.5, 0.75)
    l1_bot_pos = (0.5, 0.25)
    
    # Level 2
    l2_top_top_pos = (0.85, 0.85)
    l2_top_bot_pos = (0.85, 0.65)
    l2_bot_top_pos = (0.85, 0.35)
    l2_bot_bot_pos = (0.85, 0.15)

    # Box styling
    box_props = dict(boxstyle='square,pad=0.5', 
                     facecolor='white', 
                     edgecolor='#333333', 
                     linewidth=1.0)

    # Draw Lines (Connections)
    # Root to Level 1
    draw_link(ax, root_pos, l1_top_pos)
    draw_link(ax, root_pos, l1_bot_pos)
