#### Task Description

**Given:** A school administrator collected data on standardized test scores for students enrolled in two different tutoring programs. The five-number summaries are shown below:

| Statistic | Program X | Program Y |
|-----------|-----------|-----------|
| Minimum | 62 | 55 |
| Q1 | 71 | 68 |
| Median | 78 | 82 |
| Q3 | 85 | 92 |
| Maximum | 94 | 99 |

Based on the summary statistics, which tutoring program produces more consistent student scores, and which program has the higher typical score?

#### Quiz Options

###### Option 1 Incorrect
Program X produces less consistent scores and has the higher typical score.


###### Option 2 Correct
Program X produces more consistent scores, but Program Y has the higher typical score.


###### Option 3 Incorrect
Program Y produces more consistent scores, but Program X has the higher typical score.


###### Option 4 Incorrect
Program Y produces more consistent scores and has a lower typical score than Program X.

##### Explanation
Consistency in scores is measured by the spread, specifically the interquartile range (IQR). Typical score refers to the center, measured by the median. 
Program X: IQR = Q3 - Q1 = 85 - 71 = 14; Median = 78. 
Program Y: IQR = Q3 - Q1 = 92 - 68 = 24; Median = 82. 
Program X has the smaller IQR (14 < 24), indicating more consistent scores. Program Y has the higher median (82 > 78), indicating a higher typical score.

##### Distractors

###### Option 1
This option incorrectly claims Program X is less consistent (it actually has a smaller IQR of 14 vs. 24) and incorrectly identifies Program X as having the higher typical score (its median of 78 is lower than Program Y's 82).

###### Option 3
This option incorrectly claims Program Y has more consistent scores (it has a larger IQR of 24 vs. 14) and incorrectly claims Program X has the higher typical score (it has a lower median of 78 vs. 82).

###### Option 4
This option incorrectly claims Program Y has more consistent scores (it has a larger IQR of 24 vs. 14) and incorrectly claims Program Y has a lower typical score (its median of 82 is actually higher than Program X's 78).
