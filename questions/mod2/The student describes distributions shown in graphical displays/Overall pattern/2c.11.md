##### Explanation
A left-skewed (negatively skewed) distribution is characterized by the majority of data points clustered at higher values with a tail that stretches toward lower values. In this dot plot, most students earned scores in the 85-100 range, while a smaller number of students scored progressively lower, creating a visible tail extending toward 50 points. This pattern is common in educational assessments where the majority of students demonstrate proficiency while a subset of students struggles with the material.

##### Distractors
###### Option 1
The distribution is symmetric with scores evenly spread around 75 points — Misidentifies the clustering pattern. A symmetric distribution would have approximately equal amounts of data on either side of the center. This dot plot clearly shows concentration at the high end, not balanced around the midpoint. This distractor targets students who may default to assuming distributions are symmetric or who confuse the midpoint of the possible score range with the actual center of the data.

###### Option 2
The distribution is skewed right with a tail extending toward higher scores — Reverses the direction of skewness. Right skewness (positive skew) occurs when data clusters at lower values with a tail toward higher values, which is the opposite of what this dot plot shows. This is a common error for students who confuse the direction of the tail with the direction of the skew, or who mix up the terms "left" and "right" skewness.

###### Option 4
The distribution is uniform with approximately equal numbers of students at each score level — Fails to recognize the uneven distribution of dots. A uniform distribution would display roughly the same number of dots at each score value across the range. The clear concentration of dots at high scores with decreasing frequency toward lower scores indicates a non-uniform pattern. This distractor targets students who may overlook the clustering in the data.

import matplotlib.pyplot as plt
import numpy as np

def setup_style():
    """Configure matplotlib style to match scientific plotting standards."""
    plt.rcParams['font.family'] = 'DejaVu Sans'
    plt.rcParams['font.size'] = 10
    plt.rcParams['axes.titlesize'] = 14
    plt.rcParams['axes.titleweight'] = 'bold'
    plt.rcParams['axes.labelsize'] = 12
    plt.rcParams['axes.labelcolor'] = '#333333'
    plt.rcParams['xtick.labelsize'] = 10
    plt.rcParams['ytick.labelsize'] = 10
    plt.rcParams['xtick.color'] = '#666666'
    plt.rcParams['ytick.color'] = '#666666'
    plt.rcParams['axes.edgecolor'] = '#333333'
    plt.rcParams['axes.linewidth'] = 1.5
    plt.rcParams['grid.color'] = '#CCCCCC'
    plt.rcParams['grid.linewidth'] = 0.5
    plt.rcParams['figure.facecolor'] = 'white'
    plt.rcParams['axes.facecolor'] = 'white'

def plot_image():
    """Generate the scientific visualization."""
    setup_style()

    fig, ax = plt.subplots(figsize=(10.24, 10.24))

    # Hide top and right spines
    ax.spines['top'].set_visible(False)
    ax.spines['right'].set_visible(False)

    # Configure grid behind data (horizontal only)
    ax.set_axisbelow(True)
    ax.yaxis.grid(True, linestyle='-', color='#CCCCCC', linewidth=0.5)
    ax.xaxis.grid(False)

    # Data definition matching the exact description counts
    # Cluster (85-100): High density (4-8 dots)
    # Mid-range (70-84): Moderate density (2-4 dots)
    # Tail (50-69): Sparse density (1-2 dots)
    data_counts = {
        50: 1, 55: 1, 62: 1, 65: 2, 68: 1,
        72: 2, 75: 3, 78: 2, 80: 4, 82: 3,
        85: 4, 88: 6, 90: 5, 92: 7, 95: 8, 98: 6, 100: 7
    }

    x_data = []
    y_data = []

    # Stack dots vertically
    for val, count in data_counts.items():
        for i in range(1, count + 1):
            x_data.append(val)
            y_data.append(i)

    # Plot dots using scatter
    ax.scatter(x_data, y_data, s=250, c='#1f77b4', edgecolors='#333333', linewidth=1, zorder=3)

    # Set titles and labels
    ax.set_title("Quiz Score Distribution", color='#333333', pad=20)
    ax.set_xlabel("Quiz Score", labelpad=10)
    ax.set_ylabel("Frequency", labelpad=10)

    # Configure axes limits and ticks
    ax.set_xlim(45, 105)
    ax.set_xticks([50, 60, 70, 80, 90, 100])
    
    # Adding extra space at the top so dots aren't clipped
    ax.set_ylim(0, 9)
    ax.set_yticks(range(0, 9))

    # Ensure ticks face outward
    ax.tick_params(axis='both', direction='out', length=5)

    plt.tight_layout()
    return fig

if __name__ == "__main__":
    fig = plot_image()
    plt.savefig('plot.png', dpi=150, bbox_inches='tight')
    print("Image saved as plot.png")
