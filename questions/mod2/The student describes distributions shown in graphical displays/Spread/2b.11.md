##### Explanation
Spread describes how widely data values are dispersed. Class A has a range of 88 - 72 = 16 points, while Class B has a range of 98 - 45 = 53 points. Since Class B's scores cover a wider interval, Class B demonstrates greater spread. A larger range indicates that the data points are more dispersed, which is a fundamental concept in understanding data distributions.

##### Distractors
###### Option 1
Class A demonstrates greater spread — Reverses the comparison. Students might miscalculate the ranges or reverse their comparison, thinking smaller ranges indicate more spread. This tests whether candidates can correctly compute and interpret range values.

###### Option 3
Both classes demonstrate equal spread — Ignores calculation. The ranges are clearly different (16 vs 53 points). Students who don't perform the subtraction might assume similarity without verification, or may confuse spread with other statistical concepts like central tendency.

###### Option 4
Spread cannot be determined from this data — Overly cautious interpretation. While range is just one measure of spread, it is a valid and direct way to compare dispersion. Candidates who are uncertain about the validity of range as a spread measure might select this, but range provides legitimate information about data dispersion for comparative purposes.
