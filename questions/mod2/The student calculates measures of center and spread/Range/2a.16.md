##### Explanation
The range is calculated by subtracting the minimum value from the maximum value in a data set. In the given set, the maximum score is 94 and the minimum score is 72. Therefore, the range is $94 - 72 = 22$ points.

##### Distractors
###### Option 2
Subtracts the first value in the list (72) from the last value in the list (79). This targets candidates who incorrectly interpret "range" as the difference between the endpoints of the provided data sequence ($79 - 72 = 7$).

###### Option 3
Subtracts the minimum value (72) from the second-highest value (91). This targets candidates who fail to identify the absolute maximum in an unsorted list.

###### Option 4
Subtracts the second-lowest value (76) from the maximum value (94). This targets candidates who identify the correct maximum but fail to identify the absolute minimum in an unsorted list.
