#### Task Description

**Given:** A system administrator is comparing the daily peak connection counts for two different servers over five days.

*   **Server A:** 450, 520, 480, 600, 410
*   **Server B:** 300, 850, 400, 950, 350

##### Explanation
To find the difference between the ranges, first calculate the range for each server:
1.  **Server A:** The maximum value is 600 and the minimum value is 410. Range A = $600 - 410 = 190$.
2.  **Server B:** The maximum value is 950 and the minimum value is 300. Range B = $950 - 300 = 650$.
3.  **Difference:** Subtract Range A from Range B: $650 - 190 = 460$.

##### Distractors
###### Option 1
This is the range of Server A ($600 - 410 = 190$). The student may have stopped after calculating the first range or misunderstood the question as asking for the range of the first dataset.

###### Option 3
This is the range of Server B ($950 - 300 = 650$). The student may have calculated the range of the more variable dataset but failed to perform the final subtraction to find the difference between the two ranges.

###### Option 4
This is the difference between the maximum values of the two datasets ($950 - 600 = 350$). The student may have mistakenly believed that the difference between ranges is equivalent to the difference between the peaks of the datasets.
