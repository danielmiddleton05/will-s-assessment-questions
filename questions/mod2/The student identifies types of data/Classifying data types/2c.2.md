##### Explanation
Customer satisfaction ratings represent categorical ordinal data. This data is categorical because the responses are labels or categories rather than numerical measurements. It is ordinal because these categories have a meaningful order or ranking (such as Poor, Fair, Good, and Excellent). The distinguishing feature of ordinal data is that while the categories can be ranked, the intervals between categories are not necessarily equal or measurable.

##### Distractors

###### Option 1
The type of operating system installed — Confuses ordinal with nominal categorical data

This targets students who recognize the data as categorical but fail to distinguish between nominal and ordinal types. Operating system type is categorical nominal data because the categories have no inherent order or ranking.

###### Option 3
The number of software bugs reported each month — Confuses categorical ordinal with quantitative discrete data

This targets students who confuse ranked categories with counted numerical values. Bug counts are quantitative discrete data because they represent countable whole numbers that can be used in mathematical calculations. Unlike ordinal categories, discrete counts have equal intervals between values.

###### Option 4
The amount of data storage used measured in gigabytes — Confuses categorical ordinal with quantitative continuous data

This targets students who may not recognize the distinction between ranked categories and measured quantities. Storage usage in gigabytes is quantitative continuous data because it can take any value within a range, including decimals (e.g., 45.7 GB). Continuous data represent measurements, not ranked categories.
