#### Task Description

**Given:** A healthcare team collects data from five urgent-care clinics. For each patient visit, the team records:

- **Wait time** (minutes from check-in to seeing a clinician)  
- **Satisfaction score** (0–100)

The team plots these values in the scatterplot below.

A manager wants to develop a regression model from this data. Based on what the scatterplot shows, what should the team do first?

###### Option 2 Incorrect

##### Explanation
The scatterplot shows **several distinct groups (clusters) of points** and a few **outliers** (isolated points). The clusters likely correspond to different clinics or workflows. Drawing one regression line through all the points without first understanding why the data groups this way can give a misleading picture. The best first step is to **investigate the clusters**—for example, by checking whether each cluster comes from a different clinic—before deciding how to model the data.

##### Distractors

###### Option 1
This targets students who focus on outliers as the main issue and believe that removing them is sufficient preparation for regression, overlooking that the remaining data still forms distinct clusters that need to be understood before any model is fit.

###### Option 2
This targets students who jump to a summary statistic as the logical first step, not recognizing that a single correlation coefficient computed across distinct clusters can be misleading and does not reveal why the data is grouped.

###### Option 4
This targets students who mistake the separated clusters for a single curved trend, rather than recognizing that the points form distinct groups.

```python
import matplotlib.pyplot as plt
import numpy as np

def setup_style():
    """Configure matplotlib style to match scientific plotting standards."""
    plt.rcParams['font.family'] = 'DejaVu Sans'
    plt.rcParams['font.size'] = 10
    plt.rcParams['axes.titlesize'] = 14
    plt.rcParams['axes.titleweight'] = 'bold'
    plt.rcParams['axes.titlecolor'] = '#333333'
    plt.rcParams['axes.labelsize'] = 12
    plt.rcParams['axes.labelcolor'] = '#333333'
    plt.rcParams['xtick.labelsize'] = 10
    plt.rcParams['ytick.labelsize'] = 10
    plt.rcParams['xtick.color'] = '#666666'
    plt.rcParams['ytick.color'] = '#666666'
    plt.rcParams['axes.edgecolor'] = '#333333'
    plt.rcParams['axes.linewidth'] = 1.0
    plt.rcParams['grid.color'] = '#E0E0E0'
    plt.rcParams['grid.linewidth'] = 0.5
    plt.rcParams['figure.facecolor'] = 'white'
    plt.rcParams['axes.facecolor'] = 'white'

def plot_image():
    """Generate the scientific visualization."""
    setup_style()

    fig, ax = plt.subplots(figsize=(10.24, 10.24))

    np.random.seed(42)

    # Cluster 1: Low wait, High satisfaction
    x1 = np.random.uniform(10, 25, 20)
    y1 = np.random.uniform(85, 98, 20)

    # Cluster 2: Medium wait, Medium-High satisfaction
    x2 = np.random.uniform(35, 50, 20)
    y2 = np.random.uniform(65, 80, 20)

    # Cluster 3: High wait, Medium-Low satisfaction
    x3 = np.random.uniform(60, 80, 20)
    y3 = np.random.uniform(45, 60, 20)

    # Cluster 4: Very High wait, Low satisfaction
    x4 = np.random.uniform(90, 110, 20)
    y4 = np.random.uniform(20, 40, 20)

    # Outliers
    x_outliers = np.array([120, 15, 75, 130])
    y_outliers = np.array([90, 10, 15, 55])

    x = np.concatenate([x1, x2, x3, x4, x_outliers])
    y = np.concatenate([y1, y2, y3, y4, y_outliers])

    ax.scatter(x, y, 
               color='#1f77b4', 
               edgecolors='#000000', 
               linewidth=0.8, 
               s=100, 
               alpha=1.0, 
               zorder=3)

    ax.set_xlim(0, 140)
    ax.set_ylim(0, 100)
    
    ax.set_xlabel("Wait time (minutes)")
    ax.set_ylabel("Satisfaction score")
    ax.set_title("Wait Time vs. Patient Satisfaction", pad=20)

    ax.grid(True, linestyle='-', which='major')
    ax.set_axisbelow(True)
    
    ax.spines['top'].set_visible(False)
    ax.spines['right'].set_visible(False)
    
    ax.tick_params(direction='out', length=6, width=1)

    plt.tight_layout()
    return fig

if __name__ == "__main__":
    fig = plot_image()
    plt.savefig('plot.png', dpi=150, bbox_inches='tight')
    print("Image saved as plot.png")
```
