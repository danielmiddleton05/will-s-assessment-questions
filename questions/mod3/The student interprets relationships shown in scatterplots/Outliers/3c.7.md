#### Task Description

**Given:** A software company plots the number of hours spent on quality assurance (QA) testing against the number of post-release bugs for 20 recent projects, as shown in the scatterplot below.

![scatterplot displaying hours of QA testing on the horizontal axis versus number of post-release bugs on the vertical axis for 20 software projects, showing a general negative correlation where more QA hours correspond to fewer bugs, with one isolated data point near 50 QA hours showing an unusually high bug count](https://k3-production-bucket.s3.amazonaws.com/uploads/8799e93f-34a2-4c55-9dc1-a98cf3fa00af_optimized.jpg)

One project had 50 hours of QA testing but 45 post-release bugs — far more than any other project with a similar number of QA hours. Why is this data point best classified as an outlier?

#### Quiz Options

###### Option 1 Correct
It deviates substantially from the overall pattern formed by the rest of the data.


###### Option 2 Incorrect
It has the highest number of post-release bugs among all projects.


###### Option 3 Incorrect
It lies directly on the line of best fit drawn through the data.


###### Option 4 Incorrect
It reinforces the general trend observed across the other data points.

##### Explanation
An outlier is defined as a data point that falls far from the general pattern of the rest of the data. The project with 50 QA hours and 45 bugs deviates substantially from the negative trend shown by the other projects, where more QA testing generally corresponds to fewer bugs. This significant departure from where similar data points cluster is precisely what makes it an outlier. The correct answer identifies this defining characteristic — deviation from the overall pattern — as the reason for the classification.

##### Distractors
###### Option 2
Having the highest value on a single variable does not automatically make a data point an outlier. An outlier is defined by its deviation from the overall pattern, not by having an extreme value on one axis. A project with the most post-release bugs could still align with the general trend if it also had very few QA hours.

###### Option 3
A data point that lies on the line of best fit follows the overall trend of the data — the exact opposite of what defines an outlier. The project with 50 QA hours and 45 bugs falls far above where the line of best fit would predict, which is precisely why it is an outlier. If it were on the line of best fit, it would be a well-fitting observation, not an unusual one.

###### Option 4
This option is the opposite of what makes the point an outlier. A data point that reinforces the general trend would be considered a representative or typical observation. The described project defies the negative trend by showing a high bug count despite extensive QA testing, which is why it is an outlier rather than a confirmation of the pattern.
