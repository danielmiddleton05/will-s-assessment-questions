#### Task Description

A site reliability engineer is studying the relationship between **requests per second (RPS)** and **CPU utilization (%)** for a web service. The scatterplot shows 60 one‑minute observations that form a strong upward linear pattern. Two additional one‑minute observations are being considered for inclusion:

- **Point A** is far to the upper right but lies along the same overall upward pattern.
- **Point B** has low RPS but unusually high CPU utilization and sits far from the main pattern.

![Scatterplot of requests per second vs CPU utilization with a tight upward-trending cloud of points and two labeled candidate points A and B in different locations](https://k3-production-bucket.s3.us-east-1.amazonaws.com/uploads/6p4bXqzYXXs3S3NAT_plot_(10).png)

How will the correlation coefficient ($r$) most likely change if **point A** is added to this dataset, and how will it most likely change if **point B** is added?

##### Explanation
Correlation measures how tightly points follow a straight-line pattern.  
- **Point A** extends the existing positive linear trend (it is extreme but consistent with the pattern), which typically makes $r$ **closer to +1**.  
- **Point B** does not follow the established linear pattern (it is extreme and “off-trend”), which pulls $r$ **toward 0** and therefore **decreases** the correlation.

##### Distractors

###### Option 1
Assumes any extreme point will weaken the correlation. Points that extend the existing linear pattern can strengthen $r$ rather than reduce it.

###### Option 2
Assumes any extreme point increases correlation. An off-pattern point (like B) reduces the consistency of the linear relationship and lowers $r$.

###### Option 4
Reflects the misconception that adding one point has little effect. Correlation can be sensitive to a single influential point, especially one far from the main cluster.

import matplotlib.pyplot as plt
import numpy as np

def setup_style():
    """Configure matplotlib style to match scientific plotting standards."""
    plt.rcParams['font.family'] = 'DejaVu Sans'
    plt.rcParams['font.size'] = 10
    plt.rcParams['axes.titlesize'] = 14
    plt.rcParams['axes.titleweight'] = 'bold'
    plt.rcParams['axes.labelsize'] = 12
    plt.rcParams['axes.labelcolor'] = '#333333'
    plt.rcParams['xtick.labelsize'] = 10
    plt.rcParams['ytick.labelsize'] = 10
    plt.rcParams['xtick.color'] = '#666666'
    plt.rcParams['ytick.color'] = '#666666'
    plt.rcParams['axes.edgecolor'] = '#333333'
    plt.rcParams['axes.linewidth'] = 1.0
    plt.rcParams['grid.color'] = '#E0E0E0'
    plt.rcParams['grid.linewidth'] = 0.5
    plt.rcParams['grid.linestyle'] = '-'
    plt.rcParams['figure.facecolor'] = 'white'
    plt.rcParams['axes.facecolor'] = 'white'
    plt.rcParams['xtick.direction'] = 'out'
    plt.rcParams['ytick.direction'] = 'out'

def plot_image():
    """Generate the scientific visualization."""
    setup_style()

    fig, ax = plt.subplots(figsize=(10.24, 10.24))

    # Hide top and right spines
    ax.spines['top'].set_visible(False)
    ax.spines['right'].set_visible(False)
    
    # Configure grid behind data
    ax.set_axisbelow(True)
    ax.grid(True)

    # 1. Generate Main Data (approx 60 points)
    # Target trend: from (100, 10) to (800, 80)
    # Slope = (80 - 10) / (800 - 100) = 70 / 700 = 0.1
    # Intercept: 10 = 0.1 * 100 + b -> b = 0
    np.random.seed(42)  # Ensure reproducibility
    n_points = 60
    
    # Generate x values evenly spread between 100 and 800 with some randomness
    x_main = np.random.uniform(100, 800, n_points)
    
    # Generate y values: y = 0.1x + noise
    # Noise kept small for "tight" pattern
    noise = np.random.normal(0, 2.5, n_points) 
    y_main = 0.1 * x_main + noise
    
    # Clip y values just in case noise pushes them out of bounds, though unlikely here
    y_main = np.clip(y_main, 0, 100)

    # 2. Define Special Points
    # Point A: (950, 95) - fits trend
    pt_a_x, pt_a_y = 950, 95
    
    # Point B: (200, 90) - outlier (high CPU, low RPS)
    pt_b_x, pt_b_y = 200, 90

    # 3. Plotting
    # Main cluster
    ax.scatter(x_main, y_main, 
               color='#1f77b4', 
               edgecolor='#000000', 
               linewidth=0.5, 
               s=100, 
               alpha=0.9, 
               label='Observations')

    # Point A
    ax.scatter(pt_a_x, pt_a_y, 
               color='#d62728', 
               edgecolor='#000000', 
               linewidth=0.5, 
               s=150, 
               zorder=5) # Ensure it sits on top

    # Point B
    ax.scatter(pt_b_x, pt_b_y, 
               color='#d62728', 
               edgecolor='#000000', 
               linewidth=0.5, 
               s=150, 
               zorder=5)

    # 4. Annotations
    offset_x = 25
    offset_y = -5
    
    ax.text(pt_a_x + offset_x, pt_a_y + offset_y, "A", 
            fontsize=14, fontweight='bold', color='black', ha='left', va='top')
    
    ax.text(pt_b_x + offset_x, pt_b_y + offset_y, "B", 
            fontsize=14, fontweight='bold', color='black', ha='left', va='top')

    # 5. Labels and Limits
    ax.set_xlabel("Requests per second (RPS)")
    ax.set_ylabel("CPU Utilization (%)")
    
    ax.set_xlim(0, 1050) # Extend slightly to fit label A
    ax.set_ylim(0, 105)
    
    # Explicit ticks based on description ranges
    ax.set_xticks(np.arange(0, 1001, 200))
    ax.set_yticks(np.arange(0, 101, 20))

    plt.tight_layout()
    return fig

if __name__ == "__main__":
    fig = plot_image()
    plt.savefig('plot.png', dpi=150, bbox_inches='tight')
    print("Image saved as plot.png")
