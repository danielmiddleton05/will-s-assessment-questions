#### Task Description

**Given:** A college learning center uses a regression model to predict a student's final course percentage based on two factors: the number of tutoring visits and average weekly study hours. The model is:

$$
\text{Final course percentage} = 54 + 2.8(\text{Number of tutoring visits}) + 1.1(\text{Average weekly study hours})
$$

What is the response variable in this model?

#### Quiz Options

###### Option 1 Incorrect
Number of tutoring visits


###### Option 2 Incorrect
Average weekly study hours


###### Option 3 Correct
Final course percentage


###### Option 4 Incorrect
The student's grade point average

#### Internal Notes

##### Competency

##### Evidence Statement
The student identifies explanatory and response variables.

##### Aligned Content
Explanatory vs response variables

##### Domain
Education

##### Explanation
In a regression model, the response variable is the outcome being predicted and appears on the left side of the equation. Here, the model predicts **final course percentage**, so that is the response variable.

##### Distractors

###### Option 1
Number of tutoring visits — This is an explanatory variable used to predict the outcome. A common error is selecting a predictor because it is one of the variables being studied.

###### Option 2
Average weekly study hours — This is also an explanatory variable in the model. Students may confuse inputs (predictors) with the output (response).

###### Option 4
The student's grade point average (GPA) — GPA is a related academic measure but is not the variable being predicted in this model. Students may confuse final course percentage with GPA because both describe academic performance, but the model specifically predicts final course percentage.
