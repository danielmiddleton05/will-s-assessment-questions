#### Task Description

**Given:** A university researcher investigates whether **weekly study hours** can be used to predict **final exam scores** (measured in points). Both variables are quantitative. Which of the following correctly identifies the roles of these variables?

#### Quiz Options

###### Option 1 Correct
Weekly study hours is the explanatory variable, and final exam scores is the response variable.


###### Option 2 Incorrect
Weekly study hours is the response variable, and final exam scores is the explanatory variable.


###### Option 3 Incorrect
Weekly study hours and final exam scores are both explanatory variables.


###### Option 4 Incorrect
Weekly study hours and final exam scores are both response variables.

##### Explanation
To determine the variable roles, we must identify which variable is the predictor and which is the outcome. In this scenario, **weekly study hours** is the explanatory variable (the predictor) because it is the factor being used to make the prediction. **Final exam scores** is the response variable (the outcome) because it is the value being predicted based on study time.

##### Distractors
###### Option 2
This distractor targets students who fail to distinguish the direction of the relationship. It reverses the roles by incorrectly labeling the outcome (exam scores) as the explanatory variable and the predictor (study hours) as the response variable.

###### Option 3
This distractor suggests that both variables are predictors. This may occur if a student confuses a predictive relationship with a simple correlation where roles are not assigned, or incorrectly believes multiple predictors are being used.

###### Option 4
This distractor suggests that both variables are outcomes. This would imply there is no explanatory variable being measured to explain the variation, which contradicts the context of using one variable to predict another.
